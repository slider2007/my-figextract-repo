FigExtract

Извлечение изображений из Figma-проекта через API token и публичную ссылку. Этот дистрибутив рассчитан на развёртывание на VPS под Debian 12 без Docker: Node.js-приложение, systemd unit и reverse proxy через Nginx.

Токен отправляется только на ваш сервер FigExtract. Сервер уже обращается к Figma API и не раскрывает токен в браузерных запросах к внешнему домену.
