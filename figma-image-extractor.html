FigExtract — Figma Image Extractor

Инструмент подключается к Figma REST API по personal access token, читает структуру файла и получает экспортные URL изображений для найденных нод.

Поддерживаются ссылки вида /file/KEY, /design/KEY и /proto/KEY. Запросы выполняются в браузере напрямую к api.figma.com.
